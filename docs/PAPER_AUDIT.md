## 其余离散化约定

- 像素中心是 `(x+0.5,y+0.5)`；投影量化为 floor。UV 使用纹理中心最近邻（floor(u*W_env)）。论文没有交代框架 `align_corners`。
- source 或 target 轨迹中心在图像外则跳过；patch 边缘裁切。轨迹在相机后方跳过。
- visibility 首帧或目标帧为 false 则不传播。默认输入全 true，不额外估计稠密遮挡。z-buffer 只解决已给出 patch 之间冲突。
- 不加噪声重采样去重、不做白化、不进行方差归一化、不补 dense flow、不改变 patch 几何。这些都不是本次默认实现。
- `preserve_reference` 下首帧未覆盖区的 owner=-2，后续球面区域 owner=-1；track_coverage 独立记录，避免把完整参考帧当作轨迹覆盖。

## 与上一版的实质差异

1. 方差保持混合→普通线性混合（仍标注公式解释）：θ=.2 理论方差从 1 变为 .68，**不强行修复**。
2. 球面纹理由 latent×4→image×4；增加完整图像射线取样到 latent 的显式环节。
3. 首帧完整 iid 参考源保留，而不是仅保留 patch 内的 iid；两种合成策略均保留诊断以体现未解决歧义。
4. 主可视化增加混合后的最终噪声面板；不再只展示 raw 然后报告另一种噪声的统计。
5. 主场景补齐 1024 条轨迹与静态背景；相机运动不再仅测试球面分支。合成输入变化意味着新旧总体指标不是单一变量消融。
6. 输出保存配置与版本，旧代码/结果保留在原 CameraNoise 工作区，本独立仓库仅包含 v2。只对默认路径做论文对齐，未借复现之名加入改进方案。

## 可证实与不可证实

测试验证投影缩放、附录求交/UV、首帧原样保留、轨迹复制、z-buffer、线性混合统计以及噪声来源恒等性。独立随机源索引决定 raw 协方差，线性混合后的不同位置相关系数理论上乘以 `(1-θ)^2 / ((1-θ)^2+θ^2)`。

保持单点 Gaussian 不等于保持空间独立。线性混合后单点理论上仍为 Gaussian，但方差不是 1。无法用“论文宣称 Gaussianity”反推出未写明的归一化方式。当前结果不证明官方代码等价、不证明论文视频效果、不证明论文全部实验可复现。
